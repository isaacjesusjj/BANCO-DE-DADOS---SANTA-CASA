# Banco de Dados - Santa Casa

Repositorio academico voltado ao estudo e organizacao de banco de dados para um projeto relacionado a Santa Casa.

## Objetivo

Documentar a parte de banco de dados do projeto, com foco em organizacao de informacoes, estrutura dos dados e apoio ao desenvolvimento de uma solucao academica.

## Conhecimentos praticados

- Modelagem de dados
- Organizacao de informacoes
- Estrutura de banco de dados
- Documentacao tecnica
- Git e GitHub

## Relacao com tecnologia

Este projeto demonstra interesse por analise, organizacao e estrutura de dados, habilidades importantes para areas como desenvolvimento, analise de sistemas, suporte tecnico e dados.
